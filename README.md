# Sevi-py Homebrew Tap

Homebrew casks for [Hangtime](https://github.com/Sevi-py/hangtime), a macOS menu bar app and widgets that show
how much of your AI coding subscriptions (Claude Code, Codex, Grok, Antigravity) you have left.

```sh
brew install --cask sevi-py/tap/hangtime
```

Update with `brew upgrade --cask hangtime` (Hangtime can also do this for you). The cask is updated automatically
by Hangtime's release workflow.
